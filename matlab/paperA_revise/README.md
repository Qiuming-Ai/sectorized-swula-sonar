# Paper A MATLAB experiment archive

These folders retain the numbered MATLAB revision experiments and their
shared helpers. They are **historical numerical experiments**, not a MATLAB
port of the final Python common-front-end experiments. Their angle grids,
waveform construction, noise conventions, metrics, and scene definitions
can differ from the paper's final reported comparisons. Use the repository's
main evidence map for the source of each final figure or table.

The suite uses a 100° evaluation field with six simultaneous sectors in its
active configuration. The original common helper directory is included for
source completeness; unused exploratory subcarrier helpers are not part of
the published configuration or any supported entry point. The old standalone
draft and debug-generated copies are not included.

## Start with the independent design and scene controls

From the repository root, open MATLAB R2025b or use its batch interface:

```sh
matlab -batch "addpath('matlab/paperA_revise'); run_paperA_revision_experiments('quick',1)"
matlab -batch "addpath('matlab/paperA_revise'); run_paperA_revision_experiments('quick',1:7)"
```

The numeric indices are folder numbers, not experiment labels: `1:7` runs
A1, A3, A4, A6, A2, A5, A7 in that order. Replace `'quick'` with
`'paper'` for the corresponding archived full configuration. Outputs go
beside the selected entry in its own `results/` directory. Core scenes and
noise are generated by the archived scripts; no historical result workspace
is required for these entries.

For a later independent experiment, add only its own folder to the MATLAB
path. Its entry adds the neighboring `common/` directory when needed:

```sh
matlab -batch "addpath('matlab/paperA_revise/10_A10_channel_monte_carlo'); run_A10_channel_monte_carlo('quick')"
matlab -batch "addpath('matlab/paperA_revise/13_A13_metric_unification'); run_A13_metric_unification('quick'); run_A13_detection_audit()"
matlab -batch "addpath('matlab/paperA_revise/17_A17_geometry_export'); export_A17_geometries()"
```

For the optional plots, install the repository's Python requirements. Run the
MATLAB producer first and then run the appropriate plotting script from the
repository root, for example:

```sh
python matlab/paperA_revise/14_A14_angular_response_audit/plot_A14_angular_response.py
python matlab/paperA_revise/18_A18_workflow_figure/plot_A18_signal_pipeline.py
```

The archived A19 candidate-scoring loop uses `cfg.frequency_grid` (25-kHz
spacing in the paper configuration), whereas the archived summary field
`SearchFrequencySpacingKHz` reports `cfg.search_frequency_grid` (5 kHz).
This discrepancy is retained in the historical source. The separate final
audit uses its declared 0.01°/1-kHz grid and exact sector boundaries. Do not
infer the final manuscript's joint-search settings from that metadata field.

No raw or intermediate MAT workspaces, numerical outputs, historical
manuscript graphics, third-party meshes, or licenses for such assets are
provided here. The final paper code and frozen public data remain in the
repository's primary `code/` and `data/` directories.
